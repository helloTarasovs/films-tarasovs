# FormatRow
A typographic list of what the director makes, built to feel nothing like the gallery.

- Grid: mono index 56px · name in Cormorant 64px · one-sentence description · mono spec column (ratios, typical length), right aligned.
- Hairline above each row and below the last. No images.
- Hover: index turns `primary-text`, name shifts 8px and turns `primary-text`. If rows link to filtered work, the whole row is the link.
- Mobile: index + name on one line (name 40px), description and spec below.

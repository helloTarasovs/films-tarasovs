# ContactBlock
The closing: a quiet question in `fg-secondary`, the email set large, one primary action.

- Email in `display` (44→104px) with a hairline underline; hover turns it `primary-text` and moves the arrow up-right.
- One primary button ("Start a project", opens the brief form) and a "Copy email" text link, because mailto fails for many visitors.
- Response-time line in `caption` mono.

# TextLink
Inline action with a hairline underline and an arrow that nudges 4px on hover.

- Rest: `foreground` text, `border-strong` underline. Hover: text and underline go `primary-text` (light plum), arrow moves over `duration-ui` with `ease-cine`.
- Use for "Watch film", "Back to top", "All work". Never for the primary action.
- Disabled: `fg-disabled`, no arrow, `aria-disabled`.

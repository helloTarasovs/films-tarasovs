# SectionHeader
Eyebrow, heading and a short note on a hairline, set on the 12-column grid.

- Eyebrow spans 12; heading `h2` spans columns 1–7; note `body-s` in `fg-secondary` spans 9–12, bottom-aligned with the heading.
- Mobile: stacks, note goes under the heading at full width.
- A second phrase may follow in `fg-secondary` (`h2-contrast`, class `sr-contrast`): same roman face and size, only the color changes. No italic anywhere in the system.
